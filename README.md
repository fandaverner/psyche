# Psyché – komplexní psychologický test

Webový test osobnosti a psychického zdraví v češtině: 221 otázek a 5 behaviorálních úloh (zhruba 40–50 minut). Na konci vygeneruje podrobný osobnostní profil.

**Spuštění:** otevři `index.html` v prohlížeči, nebo použij GitHub Pages: https://fandaverner.github.io/psyche/

## Moduly
**Osobnost:** Big Five (IPIP-50), HEXACO – poctivost a pokora, temná triáda, citová vazba (ECR), sebehodnocení (Rosenberg), temperament (Eysenck), interpersonální kruh, profesní typy RIASEC

**Screening psychického zdraví:** ADHD (ASRS v1.1, WHO), autistické rysy (AQ-10), deprese (PHQ-8), úzkost (GAD-7), sociální úzkost (Mini-SPIN), OCD rysy, bipolární spektrum (MDQ), PTSD (PC-PTSD-5), hraniční rysy (MSI-BPD), alkohol (AUDIT-C), vztah k jídlu (SCOFF)

**Behaviorální úlohy:** Go/No-Go (pozornost a impulzivita), Stroopův test, číselný rozsah (pracovní paměť), BART (riziko), odkládání odměny, rozhodování v riziku, odhad času

**Implicitní část:** interpretační zkreslení (nejednoznačné situace), nucené volby mezi lichotivými výroky, měření váhání u citlivých otázek, porovnání sebeobrazu s výkonem v úlohách

**Validita:** škála lži, kontrolní otázky na pozornost, rozporné páry, opakování stejné odpovědi, rychlost

**Projektivní úlohy:** Lüscherův barevný test, Kostka v poušti

Jde o samostatný HTML soubor bez závislostí. Odpovědi zůstávají jen v prohlížeči (localStorage).

> Test slouží k sebepoznání. Není to klinický nástroj a nestanovuje diagnózy. Linka první psychické pomoci: 116 123.
