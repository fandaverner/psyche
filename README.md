# Psyché – komplexní test osobnosti

Webový psychologický test osobnosti v češtině (109 otázek). Na konci vygeneruje podrobný osobnostní profil.

**Spuštění:** stačí otevřít `index.html` v prohlížeči, nebo použít GitHub Pages: https://fandaverner.github.io/psyche/

## Z čeho test vychází
- **Big Five (IPIP-50)**: Goldberg, 1992
- **HEXACO – poctivost a pokora**: Ashton & Lee, 2004
- **Temná triáda**: Paulhus & Williams, 2002
- **Citová vazba (ECR)**: Brennan, Clark & Shaver, 1998
- **Rosenbergova škála sebehodnocení**: 1965
- **PHQ-4**: Kroenke a kol., 2009
- Temperament podle Eysencka, interpersonální kruh (Leary, Wiggins), profesní typy RIASEC (Holland)
- Projektivní úlohy: Baumův test stromu (Koch, 1949), Lüscherův barevný test, Kostka v poušti
- Kontrola validity: škála lži (princip L-škály MMPI), konzistence a rychlost odpovědí

Jde o samostatný HTML soubor bez závislostí. Odpovědi zůstávají jen v prohlížeči (localStorage).

> Test slouží k sebepoznání. Není to klinický nástroj a nestanovuje diagnózy.
